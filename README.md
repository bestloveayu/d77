# 東77 雲端手機看板

獨立於本機訂單系統的唯讀看板。GitHub Pages 只提供靜態介面；正式資料由 Cloudflare Worker 驗證 Google 登入後提供。未設定後端時，只能進入「示範資料」，不會顯示任何正式顧客資料。

## 已實作

- 總覽、顧客訂單、庫存查詢、規則進度、通知中心。
- 顧客本名、FB 暱稱、手機末三碼；完整電話及 Email 不傳到前端。
- 搜尋、排序、篩選、訂單明細、規則／卡表連結、訂購顧客跳轉。
- Google 登入後端驗證與帳號白名單。憑證只留在分頁記憶體，登出即清除。
- 雲端每五分鐘讀取；頁面每分鐘讀取已整合快照，背景分頁暫停輪詢。
- 通知事件去重、首次讀取建立基準而不推送全部舊資料；兩人各自已讀。
- 可選 ntfy 手機推播：管理員設定接收端後，個人仍須勾選啟用；勿擾時段採台灣時間。
- 日夜模式、加入手機主畫面的 manifest；不離線快取正式顧客資料。
- 季別選單與手機單欄來源設定。管理者先測試連線、確認後儲存；換季不需重新發布網站。
- 每個季別／來源設定隔離快照、通知基準與已讀；原季資料不會被新季覆蓋。
- 不呼叫原 GAS，不需改原 GAS，也不寫入任何業務試算表。

## 目前範圍與限制

- 初次部署可用私密 `SHEET_CONFIG` 作為初始來源，也可以登入後到「設定 → 管理季別來源」新增；不會自動猜測分頁或新增業務分頁。
- 管理者預設為 `ALLOWED_EMAILS` 第一個帳號，或另以 `ADMIN_EMAILS` Secret 指定；一般成員只能查看及換季。
- 雲端排程與手機推播只處理預設通知季別；舊季在查看或手動重新整理時讀取，不會把舊季事件混進當季。
- 表單訂單與手動訂單分列，不在看板內實際併單，避免將同名顧客誤合併。
- 讀取現有 `_collaboration_v1` 與 `_collaboration_orders_v1` 的分段 JSON 格式。
- 只有指紋與數量一致的協作資源才採用下單／出貨／寄送數量。找不到資源是「未確認」，不是 0；不能取代本機歷史來源核對。
- 名稱只接受空白／全半形標準化，或管理員設定的明確 `aliases`，不自動刪除 A、D 等前綴。
- 全新、二手庫存分開；庫存從歷年金流計算，本季收支只算選定季別。
- 未知出貨量不算缺貨；因此缺貨清單可能不完整，總覽另顯示待確認數。
- 規則只讀指定中文資料夾的直接子檔案，依 `_中文規則.pdf`、`_中文規則書.pdf`、`_中文卡牌.pdf` 命名辨識；不遍歷子資料夾，不修改分享權限。
- 未連結雲端的本機圖片不會顯示；無封面使用規則圖示，不拿其他遊戲圖片冒充。
- 未同步到雲端的一般通知、核對證明與本機配貨設定無法呈現。
- 任一必要來源讀取失敗，保留上一份完整成功快照、顯示錯誤與資料時間，不用零補值。
- 手機推播失敗不影響通知中心、原訂單或金流。第一版不承諾推播必達或補送；未設定推播時，頁面顯示尚未連接。
- 自動更新為準即時，不是即時串流。通知事件保留最近 150 則。

## 本機示範

```powershell
npm ci
npm test
npm run preview
```

開啟 `http://127.0.0.1:8788`，按「瀏覽示範資料」。資料全部為虛構，無需登入、不接本機原系統。

## 正式發布

請依 [部署說明](docs/DEPLOY.md) 完成 Google 登入、唯讀服務帳號、Worker 與 GitHub Pages。

前端網址預期為 `https://bestloveayu.github.io/d77/`，兩人共用網址、各自登入。只有 GitHub 程式碼發布不代表正式資料連線或手機推播已啟用。

## 安全界線

公開儲存庫不應包含：原系統的 `data/`、SQLite、Token、Google 服務帳號金鑰、顧客匯出檔或真實資料截圖。`public/config.js` 只允許 API 公開網址與 OAuth Client ID。Google Client Secret 不需要放前端。

資料來源給服務帳號「檢視者」，並且 OAuth scope 為唯讀。Worker 只向 Google Sheets/Drive 發出 GET；唯一的 Google POST 是服務帳號取得 OAuth access token。通知已讀及設定寫入獨立 Durable Object，與原試算表無關。

## 驗證

`npm test` 執行資料解析、安全拒絕、通知去重與個人已讀測試；`npx wrangler deploy --dry-run` 驗證 API 打包。`tests/ui.cjs` 為本機 Playwright 示例測試，執行時需調整本機 Playwright 安裝位置。

圖片沿用本機系統既有的日系季節橫幅；字體授權與 Lucide 授權標頭保留於 assets。示範頁不是實際營運資料。
